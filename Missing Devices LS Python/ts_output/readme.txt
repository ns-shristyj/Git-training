this folder stores output by ts_party scripts. For example: 

> crowdkandji.json will store all the devices found between kandji and crowdstrike by matching SerialNumber and filtering LENOVO, DEll. inc, apple

> crowdtune.json will store intune keys for all crowdstrike matched SerialNumber's. 

> keys will always store all kandji or intune keys for matched Serial Numbers
